changes:
  - Restructured into a monorepo — frontend and backend are now independent packages with a clear boundary
  - Automated CI/CD publishing pipeline via GitHub Actions — new skill versions deploy on every merged pull request
  - Multilingual support for English, Chinese (Simplified), and German via Paraglide-JS
  - New design system built on shadcn/ui with Tailwind v4
  - Content Collections for type-safe markdown authoring across docs and changelogs
  - New CLI tool for installing and managing skills directly from the terminal
  - All existing skill URLs and install commands preserved through the restructure
---

The previous build was a single TanStack Start application with the frontend and backend tightly coupled. This release splits them into separate packages within a monorepo, making it easier to deploy, scale, and iterate on each side independently. The stack itself stays the same; the structure around it changed.
