changes:
  - 重组为 Monorepo——前端与后端拆分为独立包，职责边界清晰
  - 基于 GitHub Actions 的 CI/CD 自动发布流水线——每次合并 Pull Request 后自动部署新版本
  - 通过 Paraglide-JS 支持英语、简体中文和德语多语言
  - 基于 shadcn/ui 和 Tailwind v4 的全新设计系统
  - Content Collections 支持文档和更新日志的类型安全 Markdown 编写
  - 新增命令行工具，支持直接在终端安装和管理技能
  - 重构过程中保留所有技能 URL 和安装命令

之前的版本是一个前后端紧耦合的单体 TanStack Start 应用。本次发布将其拆分为 Monorepo 中的独立包，使前后端各自可以独立部署、扩展和迭代。技术栈本身保持不变，改变的是围绕它的项目结构。
