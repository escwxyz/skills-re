description: CLI 搜索现在默认使用关键词搜索路径，与基于 FTS5 的 Registry 搜索保持一致，并避免触发 AI 搜索限流。

changes:
  - CLI 搜索现在请求关键词搜索，而不是语义 AI 搜索
  - 关键词搜索请求会绕过匿名 AI 搜索限流
  - CLI 帮助和文档现在说明基于关键词的发现方式
  - Search API 合约文档现在区分关键词模式和语义模式
---

CLI 现在走与 Registry 搜索体验相同的关键词搜索路径。这让终端搜索结果更可预测，不再消耗更严格的匿名 AI 搜索配额，也为下一版 CLI 默认使用基于 FTS5 的关键词搜索结果做好准备。
