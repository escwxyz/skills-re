Der 0.0.1-Build ist der erste interne Meilenstein — eine minimale Schleife von der Einreichung bis zur Installation, die beweist, dass das Kernkonzept funktioniert. Die Entdeckungsfunktionen sind begrenzt, aber nutzbar; der Fokus lag darauf, den End-to-End-Ablauf zu etablieren, bevor weitere Funktionen hinzugefügt werden.
