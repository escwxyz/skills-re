changes:
  - Umstrukturierung in ein Monorepo — Frontend und Backend sind nun eigenständige Pakete mit klarer Grenze
  - Automatisierte CI/CD-Publishing-Pipeline via GitHub Actions — neue Skill-Versionen werden bei jedem gemergten Pull Request deployt
  - Mehrsprachigkeitsunterstützung für Englisch, Chinesisch (Vereinfacht) und Deutsch via Paraglide-JS
  - Neues Design-System auf Basis von shadcn/ui mit Tailwind v4
  - Content Collections für typsicheres Markdown-Authoring in Docs und Changelogs
  - Neues CLI-Tool zum Installieren und Verwalten von Skills direkt im Terminal
  - Alle bestehenden Skill-URLs und Installationsbefehle durch die Umstrukturierung erhalten
---

Der vorherige Build war eine einzelne TanStack-Start-Anwendung mit eng gekoppeltem Frontend und Backend. Dieses Release trennt sie in separate Pakete innerhalb eines Monorepos, sodass jede Seite unabhängig deployt, skaliert und weiterentwickelt werden kann. Der Stack selbst bleibt gleich; die Struktur drum herum hat sich verändert.
