---
question: Wie reiche ich einen Skill ein?
order: 6
---

Das Einreichen eines Skills erfolgt in drei Schritten:

1. **Erstelle eine `SKILL.md`** in einem GitHub-Repository mit dem Frontmatter (`name`, `description`, `license`, `compatibility`, `metadata`).
2. **Verbinde deinen GitHub-Account** unter Einstellungen → Integrationen → GitHub und autorisiere die skills.re GitHub App für dieses Repository.
3. **Reiche ein** unter [skills.re/submit](/submit), wähle das Repository und den Versions-Tag aus.

Automatisierte Prüfungen laufen sofort nach der Einreichung. Wenn alles bestanden ist, ist dein Skill innerhalb weniger Minuten live. Lies die vollständige Anleitung unter [Skills einreichen](/docs/submitting-skills).
