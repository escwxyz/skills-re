---
question: 如何提交 Skill？
order: 6
---

提交 Skill 分三步：

1. **创建 `SKILL.md`** — 在 GitHub 仓库中添加所需 frontmatter（`name`、`description`、`license`、`compatibility`、`metadata`）。
2. **连接 GitHub 账户** — 在设置 → 集成 → GitHub 中授权 skills.re 的 GitHub App 访问该仓库。
3. **提交** — 前往 [skills.re/submit](/submit)，选择仓库和版本标签提交。

自动检查会在提交后立即运行。如果全部通过，你的 Skill 会在几分钟内上线。完整教程请参阅[提交 Skill](/docs/submitting-skills)。
