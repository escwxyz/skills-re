---
question: 如何为注册表做贡献？
order: 8
---

有多种方式可以做出贡献：

- **提交 Skills** — 最直接的方式。编写 `SKILL.md`、测试它，然后提交。清晰的描述和准确的兼容性标签能让你的 Skill 更容易被发现。
- **报告问题** — 如果某个已列出的 Skill 在受支持的运行时上未按描述工作，请在该 Skill 的 GitHub 仓库中打开 issue，或使用技能页面上的 **Report** 按钮标记它。
- **改进文档** — 文档源代码在 GitHub 上。打开 Pull Request 修复错误、添加示例或翻译内容。
- **传播信息** — 分享有用的 Skills，写博文，或在社区中提及 skills.re。健康的生态系统对每个人都有好处。

加入 Discord 或关注 GitHub，了解新功能和讨论动态。
