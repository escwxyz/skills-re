---
question: How can I contribute to the registry?
order: 8
---

There are several ways to contribute:

- **Submit skills** — the most direct way. Write a `SKILL.md`, test it, and submit it. Clear descriptions and accurate compatibility tags make your skill easier to discover.
- **Report issues** — if a listed skill doesn't work as described on a supported runtime, open an issue on the skill's GitHub repository or flag it in the registry using the **Report** button.
- **Improve documentation** — the docs source is on GitHub. Open a pull request to fix errors, add examples, or translate content.
- **Spread the word** — share useful skills, write blog posts, or mention the registry in your community. A healthy ecosystem benefits everyone.

Join the conversation on Discord or follow the project on GitHub to stay up to date with new features and discussions.
