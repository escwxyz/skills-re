---
question: How do I write an effective skill?
order: 3
---

The most important principle is focus — a skill that does one thing well is more useful than one that tries to cover everything.

Key guidelines:

- **Write a precise description** — the description is what users see in search results. One sentence should say exactly what the skill does.
- **Scope the instructions tightly** — tell the agent what to do, not how to think. Avoid vague directives like "be helpful."
- **Declare `allowed-tools`** — listing which tools the skill needs helps agents enforce permissions correctly.
- **Use `compatibility` accurately** — only list agents you have actually tested.
- **Test before publishing** — run the skill on your target agent and verify it behaves as described.

The [Best Practices guide](https://agentskills.io/skill-creation/best-practices) covers instruction design, resource bundling, and multi-step workflows in depth.
