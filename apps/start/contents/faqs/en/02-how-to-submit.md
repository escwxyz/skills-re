---
question: How do I submit a skill?
order: 6
---

Submitting a skill takes three steps:

1. **Create a `SKILL.md`** in a GitHub repository with the frontmatter (`name`, `description`, `license`, `compatibility`, `metadata`).
2. **Connect your GitHub account** via Settings → Integrations → GitHub and authorize the skills.re GitHub App for that repository.
3. **Submit** at [skills.re/submit](/submit), choose the repository and the version tag to submit.

Automated checks run immediately after submission. If everything passes, your skill goes live within minutes. See the [Submitting Skills](/docs/submitting-skills) guide for the full walkthrough.
